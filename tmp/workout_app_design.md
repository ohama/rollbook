# 운동 기록 웹앱 설계 (사진 업로드 = 자동 기록)

## 목표

20명 내외의 소규모 팀이 매일 운동 여부를 빠르게 기록할 수 있는 웹앱을
만든다.\
특히 **사진을 업로드하면 자동으로 해당 날짜의 운동 기록이 생성**되도록
설계한다.

모바일 사용을 기준으로 하며, 클릭 수를 최소화하는 것을 가장 중요하게
둔다.

------------------------------------------------------------------------

## 핵심 유저 시나리오

### 1. 오늘 운동 기록

-   앱 접속
-   `오늘 운동했다` 버튼 클릭 → 즉시 기록 완료

### 2. 사진으로 기록

-   `사진으로 기록` 클릭
-   촬영 또는 앨범 선택
-   업로드 완료 → 자동으로 오늘 운동 기록 생성 + 사진 첨부

### 3. 내 기록 보기

-   이번 달 달력 / 리스트
-   총 운동 횟수 확인
-   이전 달 이동 가능

### 4. 전체 회원 기록 보기

-   이번 달 기준
-   회원별 운동 횟수
-   월 이동 가능

------------------------------------------------------------------------

## 화면(정보 구조)

### 로그인/가입

-   초대 기반 가입 권장
-   로그인 상태 유지 (쿠키 세션 또는 refresh)

### 홈

-   오늘 날짜
-   이번 달 내 운동 횟수
-   큰 버튼 2개
    -   오늘 운동했다
    -   사진으로 기록
-   오늘 기록이 있으면: 첨부된 사진 썸네일 표시

### 내 기록

-   캘린더 / 리스트 전환
-   날짜 클릭 → 상세(운동 정보 + 사진)

### 전체 기록

-   회원별 횟수 테이블
-   월 선택

### 설정

-   닉네임
-   알림 여부
-   로그아웃

## 데이터 모델

### User

-   id
-   email / username
-   name
-   role (admin \| member)
-   createdAt

### WorkoutEntry

-   id
-   userId
-   date (YYYY-MM-DD)
-   type (optional)
-   minutes (optional)
-   note (optional)
-   createdAt
-   updatedAt

권장 제약:

    UNIQUE(userId, date)

→ 하루 기본 1회 기록을 쉽게 관리 가능.

### WorkoutPhoto

-   id
-   userId
-   entryId
-   date
-   storagePath or url
-   thumbnailPath (optional)
-   takenAt (optional)
-   createdAt

하나의 운동 기록에 여러 장의 사진 연결 가능.

------------------------------------------------------------------------

## 사진 업로드 시 자동 기록 규칙

서버 처리 기준:

1.  업로드 요청 수신
2.  targetDate 결정
    -   기본: 오늘 날짜
    -   옵션: EXIF 날짜 사용 가능
3.  해당 날짜의 WorkoutEntry 존재 여부 확인
4.  없으면 새로 생성
5.  사진 저장
6.  WorkoutPhoto 생성 후 entry 연결
7.  완료 응답

이미 기록이 있다면: → 기록은 유지하고 **사진만 추가**.

## API 예시

### 인증

-   POST /auth/login
-   POST /auth/logout
-   GET /me

### 운동

-   GET /workouts?month=YYYY-MM
-   POST /workouts/toggle (오늘 기록 버튼)
-   PUT /workouts/:id
-   DELETE /workouts/:id

### 사진

-   POST /photos (multipart 업로드) → 내부에서 entry 생성/연결까지 처리

### 통계

-   GET /stats/me?month=YYYY-MM
-   GET /stats/group?month=YYYY-MM

## 스토리지 & 권한

### 저장소

-   Supabase / Firebase / S3호환(R2, B2, MinIO 등)

### 접근 정책 (권장)

-   사진은 기본 private
-   로그인 사용자만 접근 가능
-   팀원에게 공개할지 여부는 옵션화

------------------------------------------------------------------------

## 성능 & 용량 관리

모바일 사진 원본은 크므로:

-   표시용 리사이즈 이미지 생성 (예: 1600px)
-   썸네일 생성 (300px)
-   업로드 제한
    -   파일당 5\~10MB
    -   하루 업로드 개수 제한 가능

전체 기록 화면에서는 사진을 기본 노출하지 않고, 상세 페이지에서만 로딩.

------------------------------------------------------------------------

## MVP 개발 범위

### 1단계

-   로그인 유지
-   오늘 운동했다 토글
-   사진 업로드 → 자동 기록
-   내 기록 월별 보기
-   전체 회원 횟수 보기

### 2단계

-   운동 종류 / 시간 입력
-   EXIF 날짜 인식
-   알림 기능
-   랭킹 / 스트릭(연속 기록)

------------------------------------------------------------------------
