# 테스트 시나리오

서비스 실행 후 Human이 직접 테스트할 시나리오입니다.

## 테스트 환경 준비

### 필수 조건
- Rollbook 서비스 실행 중 (http://localhost:4173)
- Supabase 실행 중 (http://localhost:54321)
- Chrome 또는 Safari 브라우저

### 테스트 계정
- 이메일 확인: http://localhost:54324 (Inbucket)

---

## 1. 인증 테스트

### TC-AUTH-01: 회원가입

| 단계 | 행동 | 예상 결과 |
|------|------|-----------|
| 1 | http://localhost:4173 접속 | 로그인 페이지 표시 |
| 2 | "회원가입" 링크 클릭 | 회원가입 폼 표시 |
| 3 | 이메일: test@example.com, 비밀번호: Test1234! 입력 | - |
| 4 | "회원가입" 버튼 클릭 | "이메일을 확인해주세요" 메시지 |
| 5 | http://localhost:54324 (Inbucket) 접속 | - |
| 6 | test@example.com 메일함 확인 | 인증 메일 수신 확인 |
| 7 | 메일 내 "Confirm your mail" 링크 클릭 | 인증 완료, 대시보드로 이동 |

### TC-AUTH-02: 로그인

| 단계 | 행동 | 예상 결과 |
|------|------|-----------|
| 1 | 로그인 페이지에서 이메일/비밀번호 입력 | - |
| 2 | "로그인" 버튼 클릭 | 대시보드 페이지 표시 |
| 3 | "환영합니다!" 메시지 확인 | 로그인 이메일 표시 |

### TC-AUTH-03: 로그인 상태 유지

| 단계 | 행동 | 예상 결과 |
|------|------|-----------|
| 1 | 로그인 상태에서 브라우저 새로고침 (F5) | 로그인 상태 유지 |
| 2 | 브라우저 탭 닫기 후 재접속 | 로그인 상태 유지 |
| 3 | 브라우저 완전 종료 후 재실행 | 로그인 상태 유지 |

### TC-AUTH-04: 로그아웃

| 단계 | 행동 | 예상 결과 |
|------|------|-----------|
| 1 | 대시보드 우측 상단 "로그아웃" 클릭 | 로그인 페이지로 이동 |
| 2 | 대시보드 URL 직접 입력 | 로그인 페이지로 리다이렉트 |

### TC-AUTH-05: 비밀번호 재설정

| 단계 | 행동 | 예상 결과 |
|------|------|-----------|
| 1 | 로그인 페이지에서 "비밀번호 찾기" 클릭 | 비밀번호 재설정 폼 표시 |
| 2 | 이메일 입력 후 "재설정 링크 보내기" 클릭 | 성공 메시지 |
| 3 | Inbucket에서 메일 확인 | 재설정 링크 포함 메일 수신 |
