Complete authentication system with:
- Email/password signup (AUTH-01)
- Email verification flow (AUTH-02)
- Password reset flow (AUTH-03)
- Session persistence (AUTH-04)
- Responsive UI (TECH-01)
- RLS-enabled database
  </what-built>

  <how-to-verify>
**Prerequisites:**
- Supabase local stack running: `npx supabase start`
- App running: `npm run dev`
- Mailpit open: http://localhost:54324 (check `supabase status` for exact URL)

**Test 1: Signup Flow (AUTH-01 + AUTH-02)**
1. Open http://localhost:3000
2. Click "회원가입"
3. Enter test email (e.g., test@example.com) and password (6+ chars)
4. Click "가입하기"
5. See success message: "인증 이메일을 발송했습니다"
6. Open Mailpit (http://localhost:54324)
7. Find verification email
8. Click verification link
9. Should redirect to app

**Test 2: Login Flow (AUTH-01)**
1. On login page, enter the test email and password
2. Click "로그인"
3. Should see dashboard with email displayed
4. Should see "환영합니다!" message

**Test 3: Session Persistence (AUTH-04)**
1. While logged in, refresh the page (F5)
2. Should see brief loading spinner
3. Should return to dashboard (NOT login page)
4. Open DevTools -> Application -> Local Storage
5. Verify "rollbook-auth" key exists

**Test 4: Password Reset (AUTH-03)**
1. Click logout
2. On login page, click "비밀번호를 잊으셨나요?"
3. Enter test email
4. Click "재설정 링크 보내기"
5. See success message
6. Check Mailpit for reset email
7. Click reset link
8. Enter new password
9. Click "비밀번호 변경"
10. Login with new password

**Test 5: Responsive UI (TECH-01)**
1. Open DevTools
2. Toggle device toolbar (Ctrl+Shift+M / Cmd+Shift+M)
3. Select iPhone SE (375px width)
4. Navigate through all pages:
   - Login: Form fully visible, buttons accessible
   - Signup: Form fully visible, all inputs usable
   - Forgot Password: Form visible
   - Dashboard: Header and content visible
5. No horizontal scrolling required
6. Touch targets are large enough (min 44px)

**Test 6: RLS Security**
1. Open Supabase Studio (http://localhost:54323)
2. Go to Table Editor -> profiles
3. Note the current user's profile row
4. Open SQL Editor
5. Run: `select tablename, rowsecurity from pg_tables where schemaname = 'public';`
6. Verify profiles shows `rowsecurity = t`
7. Create a second test user
8. Login as second user
9. Second user should only see their own profile in dashboard
  </how-to-verify>
