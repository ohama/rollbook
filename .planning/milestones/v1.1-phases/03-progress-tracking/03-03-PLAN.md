3. State management with React.useState:

   - error: string option (initial: None)

4. Month navigation functions:
   ```fsharp
   let goToNextMonth () =
       if currentMonth = 12 then
           setCurrentYear (currentYear + 1)
           setCurrentMonth 1
       else
           setCurrentMonth (currentMonth + 1)

   let goToPrevMonth () =
       if currentMonth = 1 then
           setCurrentYear (currentYear - 1)
           setCurrentMonth 12
       else
           setCurrentMonth (currentMonth - 1)
   ```

5. Data loading with React.useEffect:
   - Dependency array: [| box currentYear; box currentMonth |]

   - Set workouts array, handle loading and error states
   - Use promise { } computation expression

     * Calendar button (calls setViewMode Calendar)
     * List button (calls setViewMode List)
     * Active button: bg-indigo-600 text-white
     * Inactive button: bg-gray-200 text-gray-700
   - MonthlyStats component (always visible above calendar/list)
   - Conditional rendering based on viewMode:
     * Calendar -> CalendarGrid with month navigation callbacks
     * List -> WorkoutListView

   - Error state: error message in red
