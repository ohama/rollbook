<task type="auto">
  <name>Task 1: Create .env.production and update vite.config.js</name>
  <files>.env.production, vite.config.js</files>
  <action>
    1. **Read tunnel domain info** from 07-01-SUMMARY.md to get the actual frontend and API subdomains.

    2. **Create .env.production** with tunnel domain URLs:
       ```bash
       # .env.production
       VITE_SUPABASE_URL=https://<api-subdomain>
       VITE_SUPABASE_ANON_KEY=<get from `npx supabase status` output>
       ```
       Get the anon key by running `npx supabase status` and extracting the `anon key` value.
       The URL MUST use `https://` (Cloudflare Tunnel provides automatic HTTPS).

    3. **Update vite.config.js** with three changes:

       a. **preview.allowedHosts**: Add the tunnel domain and parent domain (for DNS rebinding protection per research pitfall #5):
          ```js
          preview: {
            host: '0.0.0.0',    // Listen on all interfaces for tunnel
            port: 4173,
            allowedHosts: [
              'localhost',
              '<frontend-subdomain>',
              '.<parent-domain>',  // Allow all subdomains
            ],
          },
          ```

       b. **server.allowedHosts**: Mirror preview settings for dev (optional but consistent):
          ```js
          server: {
            port: 3000,
            allowedHosts: [
              'localhost',
              '<frontend-subdomain>',
              '.<parent-domain>',
            ],
          },
          ```

       c. **workbox.runtimeCaching urlPattern**: Update the Supabase API pattern to match BOTH the cloud pattern AND the tunnel domain. The current patterns match `*.supabase.co` which will NOT match the tunnel API domain. Update to:
          ```js
          runtimeCaching: [
            {
              // Supabase API - NetworkFirst with fallback
              urlPattern: /^https:\/\/.*\/(rest|storage|auth)\/.*/i,
              handler: 'NetworkFirst',
              options: {
                cacheName: 'supabase-api',
                networkTimeoutSeconds: 10,
                expiration: {
                  maxEntries: 50,
                  maxAgeSeconds: 5 * 60
                }
              }
            },
            {
              // Auth endpoints - NetworkOnly (never cache)
              urlPattern: /^https:\/\/.*\/auth\/.*/i,
              handler: 'NetworkOnly'
            },
            {
              // Storage images - StaleWhileRevalidate
              urlPattern: /^https:\/\/.*\/storage\/.*/i,
              handler: 'StaleWhileRevalidate',
              options: {
                cacheName: 'storage-images',
                expiration: {
                  maxEntries: 100,
                  maxAgeSeconds: 24 * 60 * 60
                }
              }
            }
          ]
          ```
          This broader pattern matches both `supabase.co` URLs and tunnel API domain URLs.
          Keep auth as NetworkOnly (never cache auth tokens).

    4. **Ensure .env.production is in .gitignore** (it contains the anon key).
       Check if `.env.production` is covered by existing `.env*` gitignore patterns.
       If not, add `.env.production` to .gitignore.

    IMPORTANT: Do NOT use `.trycloudflare.com` URLs in .env.production. Use the actual tunnel domain from Plan 01.
    IMPORTANT: The `preview.host` MUST be `'0.0.0.0'` to accept connections from cloudflared (not just localhost).
  </action>
  <verify>
    - `.env.production` exists with `https://` URL for VITE_SUPABASE_URL
    - `vite.config.js` has `preview.host: '0.0.0.0'` and `preview.allowedHosts` with tunnel domain
    - `vite.config.js` workbox patterns use broader URL matching (not just `*.supabase.co`)
    - `.env.production` is gitignored (check `git check-ignore .env.production`)
  </verify>
  <done>
    .env.production created with tunnel API domain URL. vite.config.js updated with allowedHosts, preview host 0.0.0.0, and broadened PWA cache patterns.
  </done>
