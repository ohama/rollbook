<task type="auto">
  <name>Task 2: Configure Vite with Fable and Tailwind plugins</name>
  <files>vite.config.js</files>
  <action>
Create vite.config.js with:

```javascript
import { defineConfig } from 'vite'
import fable from 'vite-plugin-fable'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [
    fable({
      fsproj: './src/App.fsproj',
      jsx: 'automatic'
    }),
    tailwindcss()
  ],
  root: '.',
  publicDir: 'public',
  build: {
    outDir: 'dist',
    emptyOutDir: true
  },
  server: {
    port: 3000
  }
})
```

Note: jsx: 'automatic' enables React 17+ JSX transform (no explicit React import needed).
  </action>
  <verify>File exists and contains fable plugin pointing to ./src/App.fsproj</verify>
  <done>vite.config.js configured with Fable + Tailwind plugins</done>
</task>

<task type="auto">
  <name>Task 3: Create F# project structure with minimal app</name>
  <files>src/App.fsproj, src/Main.fs, src/index.css, public/index.html</files>
  <action>
1. Create src/App.fsproj:
```xml
<Project Sdk="Microsoft.NET.Sdk">
  <PropertyGroup>
    <TargetFramework>net8.0</TargetFramework>
  </PropertyGroup>

  <ItemGroup>
    <Compile Include="Main.fs" />
  </ItemGroup>

  <ItemGroup>
    <PackageReference Include="Fable.Core" Version="4.*" />
    <PackageReference Include="Feliz" Version="2.*" />
    <PackageReference Include="Fable.Browser.Dom" Version="2.*" />
  </ItemGroup>
</Project>
```

2. Create src/Main.fs (minimal hello world):
```fsharp
module Main

open Feliz
open Browser.Dom

[<ReactComponent>]
let App () =
    Html.div [
        prop.className "min-h-screen bg-gray-100 flex items-center justify-center"
        prop.children [
            Html.div [
                prop.className "bg-white p-8 rounded-lg shadow-md"
                prop.children [
                    Html.h1 [
                        prop.className "text-2xl font-bold text-gray-800"
                        prop.text "Rollbook"
                    ]
                    Html.p [
                        prop.className "text-gray-600 mt-2"
                        prop.text "원탭 운동 기록"
                    ]
                ]
            ]
        ]
    ]

let root = ReactDOM.createRoot(document.getElementById "app")
root.render(App())
```

3. Create src/index.css:
```css
@import "tailwindcss";
```

4. Create public/index.html:
```html
<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Rollbook - 원탭 운동 기록</title>
  <link rel="stylesheet" href="/src/index.css">
</head>
<body>
  <div id="app"></div>
  <script type="module" src="/src/Main.fs"></script>
</body>
</html>
```

5. Initialize dotnet tools:
```bash
dotnet new tool-manifest
dotnet tool install fable
dotnet restore src/App.fsproj
```
