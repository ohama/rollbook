<task type="auto">
  <name>Task 1: Create TeamDayDetailView component with user grouping logic</name>
  <files>src/Components/TeamDayDetailView.fs</files>
  <action>
Create TeamDayDetailView.fs component following research Pattern 3 (Team Day Detail View with User List):

1. **Module declaration and imports:**
   - module Components.TeamDayDetailView
   - open Feliz, Supabase.Types, Supabase.Team

2. **UserRecordGroup type:**
   ```fsharp
   type UserRecordGroup = {
       UserId: string
       DisplayName: string
       RecordCount: int
       RecordsByType: (string * int) array
       Records: WorkoutRecord array
   }
   ```

3. **groupRecordsByUser function:**
   - Create profile lookup Map (profiles |> Array.map (fun p -> p.id, p) |> Map.ofArray)
   - Group records by user_id using Array.groupBy
   - For each group: lookup profile with Map.tryFind, fallback chain: display_name → email → "Unknown User"
   - Count records by type using Array.countBy (fun r -> r.record_type)
   - Sort by DisplayName alphabetically
   - Return UserRecordGroup array

4. **TeamDayDetailView React component:**
   - Props: selectedDate, records, onBack, onUserClick
   - State: userGroups (UserRecordGroup array), loading (bool)
   - useEffect: fetch profiles via getTeamProfiles(), call groupRecordsByUser, setUserGroups, setLoading
   - Dependency array: [| box records |]

5. **UI structure:**
   - Header: back button (← 44x44px) + date heading (format: "YYYY년 M월 D일 - 팀 기록")
   - Loading state: "로딩 중..."
   - Empty state: "이 날의 기록이 없습니다" (when userGroups.Length = 0)
   - User list: iterate userGroups with Html.button (clickable)
     - Left: avatar circle (w-10 h-10 bg-indigo-100) with first letter + display name
     - Right: record type badges using Array iteration over RecordsByType
     - Badge colors: workout=green-100/700, text=blue-100/700, photo=purple-100/700
     - Badge format: icon text + "×N" if count > 1 (max display: ×99+ for count ≥ 100)
     - onClick: onUserClick group.UserId

6. **Error handling:**
   - Wrap getTeamProfiles in try-with, catch → setLoading false (graceful degradation)
   - Use Option.defaultValue for missing profiles

Follow Material Design badge patterns (pill shape, small text, colored backgrounds).
