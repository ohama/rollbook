<task type="auto">
  <name>Task 2: Create Workouts.fs module with CRUD operations</name>
  <files>src/Supabase/Workouts.fs, src/App.fsproj</files>
  <action>
Create new src/Supabase/Workouts.fs module following Phase 1 Auth.fs patterns from 01-03-SUMMARY.md.

**Module structure:**
```fsharp
module Supabase.Workouts

open Fable.Core
open Fable.Core.JsInterop
open Supabase.Client
```

**Implement 6 functions per RESEARCH.md Pattern 1:**

1. **getTodayDateString() : string**
   - Use toLocaleDateString with 'en-CA' locale for YYYY-MM-DD
   - Returns local date (not UTC) - critical for "today" logic
   - Example from RESEARCH: `now.toLocaleDateString("en-CA")`

2. **getWorkout (userId: string) (date: string) : JS.Promise<WorkoutRecord option>**
   - Query: supabase.from("workouts").select("*").eq("user_id").eq("workout_date").maybeSingle()
   - Returns None if no record, Some if exists
   - Use unbox<WorkoutRecord> (not :?>) per Phase 1 patterns

3. **upsertWorkout (userId: string) (date: string) : JS.Promise<WorkoutResponse>**
   - Create record object with createObj ["user_id" ==> userId; "workout_date" ==> date]
   - Options: createObj ["onConflict" ==> "user_id,workout_date"]
   - Call: supabase.from("workouts").upsert(record, options).select()
   - Returns unbox<WorkoutResponse>
   - **Critical:** onConflict makes operation idempotent (handles double-clicks)

4. **deleteWorkout (userId: string) (date: string) : JS.Promise<obj>**
   - Call: supabase.from("workouts").delete().eq("user_id").eq("workout_date")
   - Returns raw result object

5. **updateWorkout (userId: string) (date: string) (updates: obj) : JS.Promise<WorkoutResponse>**
   - For future editing (WORK-02)
   - Call: supabase.from("workouts").update(updates).eq("user_id").eq("workout_date").select()

6. **getWorkouts (userId: string) (startDate: string option) (endDate: string option) : JS.Promise<WorkoutRecord array>**
   - For calendar/list views (Phase 3)
   - Base query: supabase.from("workouts").select("*").eq("user_id")
   - Conditionally add .gte("workout_date") if startDate
   - Conditionally add .lte("workout_date") if endDate
   - Order by workout_date descending
   - Return unbox<WorkoutRecord array> or [||] if null

**Use promise { } computation expression for all async operations.**
