**Build and start:**
```bash
npm run build
npm run dev
```

**Test sequence:**

1. **Personal calendar ("나" 탭):**
   - Open http://localhost:5173
   - Login if needed
   - Navigate to "내 기록" tab
   - Click "달력" view
   - **Expected:** Calendar displays with count badges on dates with records
   - Click a date with records (badge visible)
   - **Expected:** Daily detail view shows with "←" back button + record list
   - Click back button
   - **Expected:** Returns to calendar view
   - Change month (< 이전 / 다음 > buttons)
   - **Expected:** View resets to calendar (not detail view)

2. **Team calendar ("우리" 탭):**
   - Stay in "내 기록" tab
   - Click "우리" tab (view scope switcher)
   - **Expected:** Team calendar displays with ALL team members' records
   - Count badges show combined team record counts
   - Click a date with team records
   - **Expected:** Daily detail view shows team records for that date
   - **Expected:** No edit/delete buttons (team view is read-only)
   - Click back button
   - **Expected:** Returns to team calendar

3. **Edge cases:**
   - Click a date with no records (badge = 0 or no badge)
   - **Expected:** Detail view shows "이 날의 기록이 없습니다"
   - Click back button
   - **Expected:** Returns to calendar
   - Switch from "나" to "우리" while in detail view
   - **Expected:** View resets appropriately

4. **Visual verification:**
   - Count badges: top-right corner, indigo-600 bg, white text, circular
   - Back button: 44x44px size, "←" symbol visible
   - Calendar days: clickable (cursor pointer on hover)
   - Detail view: displays RecordItem components correctly

**Success criteria:**

- ✅ CAL-03: "우리" 선택 시 우리의 달력 기록이 보인다
- ✅ CAL-04: 달력 날짜 클릭 시 해당 날의 기록 내용이 보인다
- ✅ CAL-05: 기록 내용에서 되돌아가기 아이콘으로 달력으로 복귀할 수 있다
