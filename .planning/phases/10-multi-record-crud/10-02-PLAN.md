
Parameters:
- `editingRecordId`: None = creating new, Some id = editing existing
- `initialText`: Pre-filled text (empty for new, existing content for edit)
- `saving`: External saving state to disable buttons during save
- `onSave`: Callback with text content when user clicks save
- `onCancel`: Callback when user clicks cancel or overlay

Implementation:
1. Internal state: `let (textContent, setTextContent) = React.useState(initialText)`
2. **Overlay**: `fixed inset-0 bg-black/50 flex items-center justify-center z-50`, onClick -> onCancel (only if not saving)
3. **Modal container**: `bg-white rounded-xl p-6 max-w-md w-full mx-4 shadow-xl`, onClick -> stopPropagation
4. **Title**: "메모 수정" if editingRecordId.IsSome, "메모 추가" if None. Use `text-lg font-semibold mb-4`
5. **Textarea**: Controlled component bound to textContent/setTextContent. `prop.placeholder "운동 메모를 입력하세요"`, `prop.autoFocus true`, className "w-full px-3 py-2 border border-gray-300 rounded-lg mb-4 min-h-[120px] focus:ring-2 focus:ring-indigo-500 focus:border-transparent outline-none resize-none"
6. **Button row**: flex gap-2 justify-end
   - Cancel button: "px-4 py-2 text-gray-600 hover:bg-gray-100 rounded-lg transition-colors", disabled when saving
   - Save button: "px-4 py-2 bg-indigo-600 text-white rounded-lg hover:bg-indigo-700 disabled:opacity-50 transition-colors", disabled when saving OR textContent.Trim() is empty
   - Save text: "저장 중..." when saving, "저장" otherwise
   - Cancel text: "취소"

The modal itself does NOT call API. It delegates to onSave/onCancel. The parent component handles API calls and state transitions.
