1. Open src/Pages/Dashboard.fs

   /// View scope for dashboard content (나 vs 우리)

- Do NOT use string literals ("Me", "Team") — use discriminated union
- Do NOT modify .js files — Fable regenerates them

<task type="auto">
  <name>Add 나/우리 tab switcher UI row to Dashboard</name>
  <files>src/Pages/Dashboard.fs</files>
  <action>
Add the "나/우리" tab switcher row to Dashboard.fs, following the established tab styling pattern.

Steps:
1. Open src/Pages/Dashboard.fs
2. Find the date navigation row added in Plan 01
3. AFTER the date navigation row and BEFORE the existing tab bar (Home/Progress/Team/Admin), insert the view scope tab switcher:
   ```fsharp
   // Row 2: View scope tabs (나/우리)
   Html.div [
       prop.className "flex gap-2 mb-6"
       prop.children [
           Html.button [
               prop.onClick (fun _ -> setViewScope Me)
               prop.className (
                   "flex-1 px-6 py-3 rounded-lg font-medium transition-colors " +
                   if viewScope = Me then
                       "bg-indigo-600 text-white"
                   else
                       "bg-gray-200 text-gray-700 hover:bg-gray-300"
               )
               prop.text "나"
           ]
           Html.button [
               prop.onClick (fun _ -> setViewScope Team)
               prop.className (
                   "flex-1 px-6 py-3 rounded-lg font-medium transition-colors " +
                   if viewScope = Team then
                       "bg-indigo-600 text-white"
                   else
                       "bg-gray-200 text-gray-700 hover:bg-gray-300"
               )
               prop.text "우리"
           ]
       ]
   ]
   ```

4. Build: `npm run build`
5. Start dev server if not running: `npm run dev`

Styling pattern:
- Reuses existing Dashboard tab pattern (lines 190-234)
- bg-indigo-600 text-white for active state (matches existing tabs)
- bg-gray-200 for inactive state with hover effect
- flex-1 for equal width buttons (50% each)
- gap-2 for spacing between buttons

Layout order:
1. Date navigation row (Plan 01)
2. View scope tabs (this task) ← NEW
3. Existing tab bar (Home/Progress/Team/Admin)
4. Content area

IMPORTANT:
- Pattern matching (if viewScope = Me then ...) is type-safe
- Tailwind classes match existing Dashboard.fs styling
- Do NOT modify .js files — Fable regenerates them
