  <action>
Modify Dashboard.fs content area to conditionally render ProgressView or TeamView based on viewScope state, and pass date props.

**CRITICAL:** This is a Fable (F#→JS) project. ALWAYS edit .fs source files, NEVER edit .js compiled output.

Steps:
1. Open src/Pages/Dashboard.fs
2. Find the content area that currently switches based on activeTab (around line 238-304)
3. Modify the Progress tab case to switch based on viewScope:
   ```fsharp
   match activeTab with
   | Home ->
       // Home tab: workout toggle, photos (no viewScope dependency, keep as-is)
       Html.div [
           prop.children [
               WorkoutToggle user.id refreshKey
               PhotoUploadButton user.id (fun () -> setRefreshKey (refreshKey + 1))
               PhotoGallery user.id
           ]
       ]
   | Progress ->
       // Progress tab: switches based on viewScope (NEW)
       match viewScope with
       | Me ->
           ProgressViewPage user.id currentYear currentMonth
       | Team ->
           TeamViewPage currentYear currentMonth
   | Team ->
       // OLD Team tab (now deprecated, could show message or hide)
       Html.div [
           prop.className "p-6 text-center text-gray-600"
           prop.text "팀 뷰는 'Progress' 탭에서 '우리'를 선택하세요"
       ]
   | Admin ->
       AdminPage()
   ```

4. Build: `npm run build`
5. Start dev server if not running: `npm run dev`

Key changes:
- Progress tab now has nested pattern match on viewScope
- ProgressViewPage receives (user.id currentYear currentMonth)
- TeamViewPage receives (currentYear currentMonth)
- OLD Team tab now shows deprecation message (or could be hidden in future)

Why nested pattern matching:
- Type-safe (compiler ensures all cases handled)
- Explicit control flow (no hidden logic)
- F# idiomatic (research Pattern 4)

IMPORTANT:
- Pass currentYear and currentMonth from Dashboard state to child components
- Do NOT pass setCurrentYear/setCurrentMonth (children are read-only consumers)
- Home tab unchanged (no viewScope dependency)
- Admin tab unchanged
- Do NOT modify .js files — Fable regenerates them
