  <how-to-verify>
**Preparation:**
1. Ensure you have at least one workout record with a photo (create one if needed)
2. Start dev server: `npm run dev`
3. Open browser to `http://localhost:5173` (or your dev URL)

**Test Case 1: 나 탭 날짜 상세 (DailyDetailView component)**
1. Click "나" tab
2. Navigate to a month with photo records (calendar shows counts)
3. Click a date with a photo record
4. Verify daily detail view shows photo thumbnail (64x64px)
5. **Hover over thumbnail** → cursor changes to pointer, opacity changes
6. **Click thumbnail** → fullscreen modal opens with expanded photo
7. **Click expanded photo** → modal stays open (does NOT close)
8. **Click black overlay area** → modal closes, returns to detail view
9. Click thumbnail again to reopen modal
10. **Press Escape key** → modal closes
11. **Test mobile scroll lock:** With modal open, try scrolling background → should not scroll

**Test Case 2: 우리 탭 유저 상세 (TeamView UserDetailView)**
1. Click "우리" tab
2. Click a date with team records
3. Click a user name with photo records
4. Repeat steps 5-11 from Test Case 1

**Test Case 3: Multiple photos in one day**
1. Create 2-3 photo records on the same date
2. Navigate to that date's detail view
3. Click each photo thumbnail → verify each opens its own photo in modal
4. Verify modal shows correct photo URL (not mixing up photos)

**Expected behavior:**
✓ Thumbnails show cursor-pointer and hover effect
✓ Clicking thumbnail opens fullscreen modal
✓ Clicking expanded photo does NOT close modal
✓ Clicking overlay or pressing Escape closes modal
✓ Background content does not scroll when modal open
✓ Modal covers entire viewport (no white bars on mobile)
✓ Photo scales to fit viewport (max-w-full max-h-full)

**Known limitations (acceptable for Phase 13):**
- Signed URLs expire after 1 hour (expected, no error handling needed)
- No pinch-to-zoom on mobile (out of scope for PHO-03)
- No image loading spinner (acceptable for fast local loads)
