  <name>Task 1: Create DateHelpers utility module</name>
  <files>src/Utils/DateHelpers.fs</files>
  <action>
Create src/Utils/DateHelpers.fs with date calculation utilities using JavaScript Date via emitJsExpr (matching existing getTodayDateString pattern from Workouts.fs).

Required functions:
1. `getDaysInMonth (year: int) (month: int) : int` - Returns days in month (28-31) using `new Date(year, month, 0).getDate()` trick
2. `getFirstDayOfMonth (year: int) (month: int) : int` - Returns day of week (0=Sunday, 6=Saturday) using `new Date(year, month-1, 1).getDay()` (remember JS months are 0-indexed)
3. `formatDateString (year: int) (month: int) (day: int) : string` - Returns YYYY-MM-DD format using sprintf (must match database DATE format)
4. `formatMonthYear (year: int) (month: int) : string` - Returns Korean format "YYYY년 M월" for display
5. `hasWorkout (date: string) (workouts: WorkoutRecord array) : bool` - Checks if date exists in workouts array

Use Fable.Core.JsInterop for emitJsExpr, import Supabase.Types for WorkoutRecord type.

**IMPORTANT:** JavaScript months are 0-indexed (0=January, 11=December) but days are 1-indexed (1-31). Subtract 1 when passing month to Date constructor.

Add module to App.fsproj before Calendar.fs (dependency order).
