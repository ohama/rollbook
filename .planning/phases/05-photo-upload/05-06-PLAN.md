  <how-to-verify>
**Test 1: Photo Upload from Desktop**

1. Open http://localhost:5173 in browser
2. Log in or create a new account
3. On the Home tab, find "사진으로 운동 기록" section
4. Click "사진 올리기" button
5. Select any image file from your computer
6. Observe:
   - "압축 중..." appears briefly
   - Progress bar appears with percentage
   - "업로드 완료! 운동 기록됨" appears on success
7. Check the workout toggle button - it should now show 💪 (worked out today)

**Test 2: Photo Gallery Display**

1. After upload, scroll down to "내 운동 사진" section
2. Verify:
   - Your uploaded photo appears
   - Date overlay shows Korean-formatted date (예: 2026년 2월 10일)
   - Photo loads properly (not broken image)
3. Refresh the page
4. Photos should still appear (persisted in storage)

**Test 3: RLS Privacy Verification**

1. Open a new incognito/private browser window
2. Go to http://localhost:5173
3. Create a DIFFERENT test account (new email)
4. Log in with this new account
5. Check "내 운동 사진" section
6. Verify: The new user should see "아직 업로드한 사진이 없습니다"
7. The new user should NOT see the first user's photos

**Test 4: Progress Indicator (Optional - Large File)**

1. Find a large image (5MB+) or use slow network throttling in DevTools
2. Upload the image
3. Observe progress bar updating smoothly from 0% to 100%

**Test 5: Mobile Camera (If Mobile Device Available)**

1. Open http://localhost:5173 on mobile phone (use ngrok or local IP)
2. Log in
3. Tap "사진 올리기"
4. Device camera should open (rear camera)
5. Take a photo
6. Observe compression and upload progress
7. Photo should appear in gallery

**Expected Results:**
- Desktop: File picker opens, photo uploads with progress, workout recorded
- Gallery: Photos display with dates, sorted by most recent
- RLS: User A's photos invisible to User B
- Mobile: Camera opens, photo captured and uploaded
  </how-to-verify>
