## Test 2: Team Workout Visibility

1. While logged in as Account A:
   - Go to "홈" tab
   - Click "오늘 운동했다" to log workout
   - Go back to "팀" tab

**Expected:**
- [ ] Account A shows "1회" workout count
- [ ] Account B still shows "0회"

2. Log out and log in as Account B:
   - Go to "팀" tab

**Expected:**
- [ ] Account A's workout is visible (shows "1회")
- [ ] Account B shows "0회"

3. Log workout for Account B:
   - Go to "홈" tab
   - Click "오늘 운동했다"
   - Go to "팀" tab

**Expected:**
- [ ] Account A shows "1회"
- [ ] Account B shows "1회"
- [ ] Total workouts shows "총 2회 운동"

## Test 4: Privacy Verification (RLS)

1. Open browser developer tools (F12) → Network tab
2. While logged in as Account B, go to "팀" tab
3. Check network request to Supabase

**Expected:**
- [ ] Request returns workout data for all users (team visibility works)

4. Try to modify Account A's workout via console:
```javascript
// This should fail due to RLS
const { data, error } = await supabase
  .from('workouts')
  .delete()
  .eq('user_id', 'ACCOUNT_A_USER_ID')
  .eq('workout_date', 'YYYY-MM-DD')
```

**Expected:**
- [ ] Delete fails (no rows affected) - RLS prevents modification
- [ ] OR: error returned indicating no permission
